# Pipe Clamp Wall Mount

A 3D-printable wall rack of angled pipe clamps. One block holds several pipes, each in an opening that leans back toward the wall, with screws driven through the back wall between the openings. The defaults fit 1-1/8" pipe.

## Features

- Pipes lean back into the wall so they stay put.
- One hidden counterbored screw per pipe.
- A tip on top and a matching socket underneath align blocks end to end.
