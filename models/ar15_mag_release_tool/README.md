# AR-15 Magazine Release Tool

A 3D-printable plunger on a textured thumb head, for pressing a recessed AR-15 magazine release.

## Features

- The plunger and head sizes are the original inch dimensions in millimeters.
- The head has a diamond grip texture cut into its sides and a rounded thumb face.
- The plunger tip is rounded.
- Set the plunger, head, tip and thumb face radii, and the texture size and depth.
