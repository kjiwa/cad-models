# Heater Vent Switch Cover

A 3D-printable cover for a heater vent switch: a flange with a half-cylinder dome over a rectangular opening. The defaults fit a 31 x 18 mm switch under a 35 mm dome.

## Features

- The opening and the dome cavity match the original fit exactly.
- The flange has rounded corners and a rounded top edge, so it does not catch hands or cloth.
- A fillet blends the dome into the flange, which is stronger there than a sharp inside corner.
- The flange bottom has a small chamfer, so the first layer does not flare into a lip.
- Set the flange thickness, dome length and diameter, wall thickness, overhang, and the rounding.

## Printing

- **Material**: PETG or ABS near a heater; PLA softens with heat.
- **Orientation**: Flange down, dome up, as modeled. No supports.
