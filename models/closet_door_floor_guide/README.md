# Closet Door Floor Guide

A 3D-printable floor guide for closet doors: a base with a middle guide and an end guide at each side, leaving a channel for each door. The defaults fit 1-3/8" doors.

## Features

- Each channel is the door thickness plus a clearance, so doors slide without binding.
- The guide tops and base corners are rounded, so doors and feet do not catch.
- Set the door thickness, clearance, base size, and guide thicknesses and height.

## Printing

- **Material**: PETG or ABS; PLA is fine indoors.
- **Orientation**: On its side, as modeled, so the layers run along each guide.
