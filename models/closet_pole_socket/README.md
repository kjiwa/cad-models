# Closet Pole Socket

A 3D-printable closet pole socket: a round base with a socket that holds the end of the pole. The closed socket takes the pole end from above; the open socket has a slot, so the pole drops in from the side. The defaults fit a 1-3/8" pole (Prime Line N 6568, for a #8 wood screw).

Derived from the [AtHome Pole Socket](https://www.printables.com/model/78232-athome-pole-socket) by William A. Adams, licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

## Features

- Pick the closed or open socket with `Part`.
- The base rim and socket lip are rounded, and the open slot entry is chamfered, so a hand or pole does not catch.
- Set the pole diameter, socket size, base size, and screw sizes.
